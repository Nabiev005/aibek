# Набиев Айбек — Портфолио

React + TypeScript + Vite менен жасалган жеке портфолио сайт. 3D графика Three.js менен (CDN аркылуу жүктөлөт).

## Иштетүү

```bash
npm install      # бир жолу
npm run dev      # иштеп чыгуу режими → http://localhost:5173
npm run build    # даяр сайт dist/ папкасына чыгат
npm run preview  # даяр билдди текшерүү
```

## Өзгөчө функциялар

### Жүктөө экраны — монитор + терминал + 😈 хакердик пранк
Сайт ачылганда монитор чыгып, терминалда `npm install`, `npm run build` жазылат. Андан кийин ар бир кирүүдө пранк башталат:
1. Монитордо "хакердик чабуул": конокко өзүнүн системасы, браузери жана экраны көрсөтүлөт.
2. Бүт экранды басып алуу: баш сөөк, **YOU HAVE BEEN HACKED**, "Бардык файлдар өчүрүлөт: 5…4…3…", фондо "өчүрүлгөн" файлдар; өтмөктүн аталышы "⚠ VIRUS DETECTED!" болуп жылтылдайт.
3. Windows'тун көк экраны (кыргызча), караңгылык.
4. Терминалда тамгалап: "aibek — хакер эмес, жөн гана тамашакөй программист 😄", `hack --undo --all` → монитор чоңоюп портфолиого кирет.

- Эч нерсе өчүрүлбөйт, эч бир маалымат эч жакка жөнөтүлбөйт.
- "Өткөрүп жиберүү" баскычы жок. Жашыруун авариялык чыгуу — **Esc**.
- `prefers-reduced-motion` күйүк болсо пранк көрсөтүлбөйт (жылтылдоо зыян болушу мүмкүн).
- Тексттер: `src/components/Loader.tsx` → `INTRO`, `makePrankScript()`, `fakeFiles()`, `PRANK_LOCATION`, `PRANK_LANGUAGE`; узактыгы — `TAKEOVER_MS`, `CHAR_MS` ж.б.

### Интерактивдүү терминал
**Ctrl + K** (Mac: ⌘ + K), менюдагы **`>_`** баскычы же Hero'догу кеңеш менен ачылат.
- Буйруктар: `help`, `whoami`, `about`, `skills`, `projects`, `open <n>`, `contact`, `ls`, `cd <бөлүм>`, `theme`, `time`, `echo`, `clear`, `exit`.
- ↑ / ↓ — мурунку буйруктар, **Tab** — буйрукту толуктоо, **Esc** — жабуу.
- 🥚 Жашыруун буйрук: `sudo hire-aibek` → конфетти атылып, "Байланыш" бөлүмүнө өтөт.
- Жаңы буйрук кошуу: `src/components/DevTerminal.tsx` → `runCommand()` жана `COMMANDS`.

### Башка эффекттер
- **Интерактивдүү фон** (`BackgroundFX.tsx`): WebGL аврора — суюктуктай агып турган жарык толкундар (скролл менен агым жылат, чычканды ээрчиген жарык) + чекит-торчо (чычкан жакындаганда чекиттер жанып четке түртүлөт, басканда толкун тарайт).
- **Hero'догу монитор** (`HeroMonitor.tsx`): код редакторунда маалыматыңыз TypeScript коду болуп тамгалап жазылат, монитор чычканды ээрчип 3D бурулат.
- **"Хакер" аталыштар:** бөлүмдөрдүн аталыштары туш келди символдордон акырындап чечмеленет (`ScrambleText.tsx`).
- **Магниттик баскычтар:** `data-magnetic` атрибуту бар элементтер чычканга тартылат (`useMagnetic.ts`).
- **Бишкектин жандуу сааты** footer'де: күндүз "иштеп жатам 💻", түнкүсүн "уктап жатам 🌙" (`lib/time.ts`).
- **DevTools консолу:** иштеп чыгуучулар консолду ачканда салам жазуусун көрүшөт.
- **Өтмөк аталышы:** колдонуучу башка өтмөккө өткөндө "👋 Кайра келиңиз!" деп өзгөрөт (`useDevExtras.ts`).
- **3D:** Hero'догу интерактивдүү форма, бөлүмдөрдөгү мини 3D объекттер, карточкалардагы 3D tilt.
- **Өзгөчө курсор** (компьютерде гана), караңгы/жарык режим, скролл анимациялары.
- `prefers-reduced-motion` күйүк болсо, бардык анимациялар азайтылат.

## Эмнени кайдан өзгөртүү керек

| Эмне | Кайда |
|---|---|
| Аты-жөн, кесиптер, байланыштар, көндүмдөр, долбоорлор, тажрыйба | `src/data.ts` |
| Сүрөттөрүңүз | `public/images/` ичине салып, `src/data.ts` → `profile.photos` |
| Долбоорлордун сүрөттөрү | `public/images/project-*.webp` (16:10 өлчөмү сунушталат) |
| Түстөр (караңгы/жарык тема) | `src/styles/global.css` башындагы `:root` өзгөрмөлөрү |
| 3D сахналардын жана фондун түстөрү | `src/lib/palette.ts` |
| Three.js версиясы | `src/lib/loadThree.ts` |
| Байланыш формасынын жөнөтүү ыкмасы | `src/components/Contact.tsx` → `onSubmit` |

## Структура

```
src/
  data.ts              ← сайттын бардык мазмуну
  App.tsx              ← бөлүмдөрдү бириктирет
  components/          ← Hero, About, Skills, Projects, Timeline, Contact, Footer,
                         HeroScene / MiniScene (3D), HeroMonitor, BackgroundFX, Loader,
                         DevTerminal, ScrambleText, Cursor, Navbar
  hooks/               ← тема, typewriter, скролл анимациясы, 3D tilt, магнит
  lib/                 ← Three.js CDN жүктөгүч, түстөр, конфетти, Бишкек убактысы
  styles/global.css    ← бардык стилдер жана анимациялар
```
